# CODSOFT Python Internship Tasks

This repository contains my Python Programming internship tasks completed for the CodSoft Internship Program.

## Task 1: To-Do List Application

A command-line To-Do List application built using Python. It helps users manage their daily tasks easily.

## Features

- Add new tasks
- View all saved tasks
- Mark tasks as completed
- Delete tasks
- Exit the application
- Simple menu-based interface

## Technologies Used

- Python
- Lists
- Dictionaries
- While loop
- For loop
- Conditional statements
- Input and output handling

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python task1_todo_list.py
```

## Sample Menu

```text
===== TO-DO LIST =====
1. Add Task
2. View Tasks
3. Mark Task as Completed
4. Delete Task
5. Exit
```
